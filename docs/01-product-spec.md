# Product specification

## Product name

Foster Memories

## One-line description

A private, local-first Android app that turns foster-pet photos and notes into
a lasting story for every animal you foster.

## Problem

Foster pets create meaningful memories, but the photos and stories are usually
scattered across a phone’s camera roll, messages, social-media posts, and
memory.

After a pet is adopted or moves on, it becomes difficult to remember:

- What they were like when they arrived
- How they progressed
- Which photos tell the real story
- What made them unique
- What milestones they reached
- What you want to remember about the goodbye

## Target user

The primary user is a pet foster who wants a private, personal journal for each
animal they foster.

This is not for rescue organizations, shelters, foster coordinators, or
multi-user teams.

## Core value proposition

Foster Memories turns scattered photos into a searchable, chronological story
for each foster pet.

## Primary jobs to be done

1. Create a dedicated story for each foster pet.
2. Quickly save a photo, note, or milestone while it is still fresh.
3. See a pet’s journey from arrival to departure.
4. Preserve personality, quirks, progress, setbacks, and funny moments.
5. Create a keepsake after the pet leaves.
6. Keep private memories private and exportable.

## User personas

### Ryan, the foster

Ryan fosters pets and takes many photos. He wants a simple place to preserve
the story of each animal without needing an organization account or complicated
rescue software.

He values privacy, offline access, local control, and easy export.

## MVP features

### Pet profiles

Each pet has:

- Name
- Species
- Breed or mix
- Sex
- Approximate age
- Arrival date
- Departure date
- Status
- Cover photo
- Backstory
- Personality description
- Notes
- Tags

Pet status values:

- Active
- Adopted
- Transferred
- Returned
- Deceased
- Unknown

### Memory entries

A memory entry contains:

- Pet
- Date
- Title
- Story or note
- Photos and/or videos
- Location
- Mood
- Tags
- Favorite flag

Memory moods:

- Happy
- Funny
- Sweet
- Proud
- Challenging
- Sad
- Neutral

### Timeline

Each pet has a reverse-chronological timeline of memories, milestones, photos,
and important dates.

### Milestones

Users can create milestones such as:

- First day home
- First full meal
- First tail wag
- First purr
- First walk
- First play session
- First night outside a crate
- First vet visit
- Weight goal reached
- Adoption day

Milestones may be linked to a memory.

### Collections

Collections are saved groupings of memories, such as:

- First week
- Funny moments
- Progress
- Before and after
- Favorite photos
- Farewell

### Search

Search across:

- Pet names
- Memory titles
- Memory notes
- Tags
- Milestones
- Locations

### Export

Users can export:

- A single memory
- A pet timeline
- A complete pet story
- Selected photos
- A PDF memory book
- A JSON backup
- A Markdown archive

## Future features

Do not build these in Phase 1:

- Cloud sync
- Account creation
- Multi-device sync
- Shared family journals
- Medical reminders
- Medication tracking
- Rescue coordination
- Adoption workflow
- Public sharing pages
- AI-generated captions
- AI-generated medical advice

## Success metrics

Because this is personal software, success is measured by actual usage:

- User creates a pet profile for each new foster.
- User adds at least one memory during the first week.
- User returns to view a past pet’s timeline.
- User exports at least one memory book or archive.
- User keeps using the app after the first foster pet leaves.
